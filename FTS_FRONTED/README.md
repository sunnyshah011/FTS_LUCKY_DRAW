# FTS Lucky Draw Frontend

React + Vite frontend for the MongoDB-backed Khushi Bazar Lucky Draw application.

## Setup

1. Copy `.env.example` to `.env`.
2. Set `VITE_API_BASE_URL` to the Express backend URL (default `http://localhost:5000`).
3. Run `npm install` and `npm run dev`.

Production build: `npm run build`.

See `../README-MIGRATION.md` for backend setup, MongoDB requirements, and data-migration cautions.
